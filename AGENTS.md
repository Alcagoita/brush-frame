# Brush Frame — project context

Read by every AI tool working in this repository. `CLAUDE.md` imports this file, so Claude Code and Codex follow the same rules.

## What this is

**Brush Frame** is a human-led way to build software with AI: eight steps from an idea to a release, where AI analyses, builds and reviews, and people make every decision that matters. It was written by Olegário Nascimento (Tech Lead and Engineering Manager), from building [Brush](https://brushaway.app) alone with AI, holding every role.

It has three parts:

1. **The framework text**: `FRAMEWORK.md`, published with a DOI on Zenodo (10.5281/zenodo.24358099, all versions).
2. **Templates** to copy: `templates/` (tickets, persona brief, rule entry, starter rule file).
3. **The setup kit**: a Claude Code plugin and Codex skill that does step 4 (Setup) for a project, then hands the first idea to a brainstorm or a design (`plugin/`, explained in `SETUP.md`).

[Pigment](https://github.com/Alcagoita/pigment) is an optional companion that shows what AI work costs. Nothing here depends on it.

## Rules

- **People decide.** Show the plan before changing anything; merges happen only on the author's word.
- **Every change goes through a pull request into `main`.** No direct pushes.
- **One version, everywhere at once.** A new version updates, together: the version line in `FRAMEWORK.md`, the Status line in `README.md`, `CHANGELOG.md`, `CITATION.cff` (`version`, `date-released`) and `.zenodo.json`.
- **Releases are normal GitHub releases, never pre-releases.** Zenodo archives only normal releases; each gets its own version DOI, listed in the README.
- **Writing style:** plain, short sentences; sentence case; the reader is a person deciding, not a machine. Say what something does, not how impressive it is.
- **Licences:** the framework text is CC BY 4.0; `templates/` and `plugin/` are CC0. Keep the headers and `LICENSE` in step.
- **No secrets, ever.** The setup kit never sees a password, token or key; nothing like that is committed, logged or pasted.
- **Artwork is generated.** Change the scripts in `assets/`, then run them; don't edit the SVG or PNG by hand.

## Checks before a pull request

- `claude plugin validate .`: the marketplace and the plugin manifest
- `bash -n plugin/skills/framework-setup/scripts/*.sh`: the scripts parse
- Run a changed script with `--dry-run` and read what it would do
- `node counter/test.mjs` when `counter/` changes
- Images: open the README on the branch in GitHub, in light and dark
